## browser

Control the current actor's project Browser. Use `open` with a public HTTP or HTTPS URL, then `content` with the returned `browser_id`. Use the page's refs or selectors for interactions. `list` shows tabs, `navigate` changes the page, and `screenshot` returns a chat image reference for `vision_load`. Uploads use project-relative paths. Load the `browser-automation` skill with `skills_tool` for action arguments and rendered-page workflows.
